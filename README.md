# מנוע חילוץ טפסי התחייבות

קורא טפסי התחייבות (PDF / תמונה), מחלץ שדות עם רמת ביטחון, שומר רשומות במסד נתונים מקומי, ומאפשר תיקון, אישור וייצוא.
הארכיטקטורה והכללים המלאים: `CLAUDE.md`. הפעלה: `streamlit run app.py` (מפתח Gemini ב-`.env`, ראו `.env.example`).

## נתונים שנשמרים מקומית (פרטיות)

| מה | איפה | מתי נמחק |
|---|---|---|
| רשומות, מצבי שדות, יומן שינויים, העלאות | `data/app.db` (SQLite) | "מחק את כל הנתונים" (מסך הרשומות, "ניהול נתונים", בתחתית), או מחיקה ידנית של הקובץ |
| תמונת כל עמוד שיש לו רשומות | `data/pages/<מזהה העלאה>/p<עמוד>.jpg` (מספרים בלבד בשמות; שם הקובץ המקורי לא נשמר) | אוטומטית כשכל הרשומות של העמוד אושרו; ב"מחק את כל הנתונים"; או מחיקה ידנית של התיקייה |
| מוני מכסה (בלי נתוני מטופל) | `data/quota_state*.json` | ידנית |
| מטמון תשובות המודל (רק ב-`PRIVACY_MODE=dev`) | `data/cache/` | ידנית |

- `data/` כולל נתוני מטופלים ונמצא ב-`.gitignore`. אין להעלות אותו ל-git.
- **איפוס המערכת למצב ריק:** מחיקה ידנית של `data/app.db` ושל התיקייה `data/pages` (כשהאפליקציה סגורה). הם ייווצרו מחדש בהעלאה הבאה.
- "מחק את כל הנתונים" סופי ואינו משפיע על קבצים שכבר הורדו (Excel / CSV / JSON).
- המסד והתמונות נכתבים בשני מצבי הפרטיות (`PRIVACY_MODE`); המצב שולט רק במטמון ובקובצי הדיבוג.

### הגדרות אחסון תמונות (`config/storage.json`)

| מפתח | ברירת מחדל | משמעות |
|---|---|---|
| `store_page_images` | `true` | `false` = לא נכתבת אף תמונת עמוד (כרטיס הרשומה יציג "אין תמונה שמורה לעמוד הזה", והעריכה ממשיכה לעבוד) |
| `keep_images_after_approval` | `false` | `false` = התמונה נמחקת כשכל הרשומות של העמוד אושרו; `true` = היא נשארת |

אפשר לדרוס בסביבה: `STORE_PAGE_IMAGES=0`, `KEEP_IMAGES_AFTER_APPROVAL=1`. בשימוש במעבדה, עם מטופלים אמיתיים, יש להחליט במפורש אם לשמור תמונות.
